Genqo.jl

Genqo.jl [1] is a hybrid Gaussian / non-Gaussian quantum optics state engine for modeling entanglement sources used in quantum networking.

It numerically computes performance metrics, such as Bell-state fidelity, probability of success, and spin-spin density matrices, for four photonic entanglement source architectures:

SourceDescription
tmsvTwo-Mode Squeezed Vacuum (the simplest Gaussian entangled state)
spdcSingle SPDC Source
zalmCascaded source [2] (equivalent to single frequency mode of a ZALM source [3])
sigsagAlternative heralded Bell pair source proposed by Yousef Chahine et al. [4]

All sources support loss modeling through bell-state measurement efficiency, detection efficiency, outcoupling efficiency, and (for ZALM) dark counts. A Python wrapper is provided for users who prefer Python; it exposes the same API via juliacall.

For an in-depth presentation of the mathematical foundations of this package, see [1].
