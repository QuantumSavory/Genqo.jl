# [Gaussian Unitaries](@id api_unitaries)

Gaussian unitaries beyond those Gabs.jl provides, written in the same style and usable
anywhere a Gabs `GaussianUnitary` is. Each is implemented for both `QuadPairBasis` (qpqp
ordering) and `QuadBlockBasis` (qqpp ordering).

```@docs
Genqo.modeswap
Genqo.greenmachine
```
