Covariance Matrix Utilities

Genqo.tools.permutation_matrix — Function
permutation_matrix(
    permutations::Vector{Int64}
) -> Matrix{Int64}

Construct a permutation matrix from a permutation vector.

Returns the n×n matrix P where P[i, permutations[i]] = 1 and all other entries are zero. Used to reorder rows/columns of a covariance matrix between mode orderings.

Parameters

  • permutations: Integer vector of length n encoding the permutation (1-indexed)

Returns

n×n Float64 permutation matrix.

Genqo.tools.reorder — Function
reorder(
    covariance_matrix::Matrix{Float64}
) -> Matrix{Float64}

Reorder a covariance matrix from qpqp to qqpp mode ordering.

Applies the permutation [1, 3, 5, ..., 2, 4, 6, ...] via a similarity transform so that all q-quadratures come before all p-quadratures. Required before calling k_function_matrix.

Parameters

  • covariance_matrix: Real covariance matrix (or BlockDiagonal) in qpqp ordering

Returns

Reordered covariance matrix in qqpp ordering.

Genqo.tools.k_function_matrix — Function
k_function_matrix(
    covariance::Matrix{Float64}
) -> Matrix{ComplexF64}

Construct the complex-valued K-matrix used to form the Gaussian contraction matrix A.

Given a physical covariance matrix (in qqpp ordering), this function forms Γ = cov + (1/2)I, computes Γ⁻¹, and then builds the complex block matrix (and its conjugate block) used in the ZALM/SPDC moment formalism. Downstream code forms A = K + G, where G encodes loss / measurement modeling, and then uses A⁻¹ as the contraction kernel for Wick evaluation via W.

Implementation note: This version is an unrolled/optimized construction that avoids intermediate block arrays and reuses an LU factorization for Γ⁻¹.

Parameters

  • covariance_matrix : Real covariance matrix in qqpp ordering

Returns

A ComplexF64 matrix K (block diagonal [BB, conj(BB)]) suitable for A = K + loss_matrix.
