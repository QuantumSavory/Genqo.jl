Projection and Metrics

project pairs a pure Gaussian state with a detection outcome and detector efficiencies. It computes nothing on its own — the result is a description of a measurement, and the work happens when a metric is requested from it.

ρ = project(st, projector([1, 1]); η = [0.9, 0.8])

tr(ρ)                      # heralding probability
fidelity(ψ, ρ)             # fidelity against a click-state target
dot(ψ', ρ, φ)              # one unnormalized density-matrix element
to_fock(ρ)                 # the whole heralded density matrix

tr and dot are additive over the click patterns of a summed projector, so a herald that several patterns satisfy needs no special handling.

Projecting

Genqo.project — Function
project(
    st::Gabs.GaussianState,
    proj::ClickProjector;
    η
) -> ProjectedPureGaussianState

Apply the detection outcome proj to the pure Gaussian state st, with per-mode detector efficiency given by the keyword η, returning a ProjectedPureGaussianState.

st must be pure with zero displacement, and st, proj and the efficiency vector must agree on the number of modes. Nothing is computed here; pass the result to tr, dot, fidelity or to_fock.

Genqo.ProjectedPureGaussianState — Type
struct ProjectedPureGaussianState <: AbstractProjectedPureGaussianState

A pure Gaussian state together with a detection outcome and per-mode detector efficiencies. Build one with project rather than calling this constructor.

Nothing is evaluated on construction: the object records what was measured, and the quantity of interest is then extracted with tr for the success probability, dot for density-matrix elements, fidelity, or to_fock.

Engines

Every metric accepts an engine keyword. Supplying one explicitly reuses its compiled moment-polynomial cache across calls; omitting it falls back to a process-wide engine for that mode count.

Genqo.HybridProjectionEngine — Type
mutable struct HybridProjectionEngine <: AbstractProjectionEngine

Reusable workspace for projections on an mds-mode circuit.

The engine holds the symbolic phase-space variables for the circuit and memoizes compiled moment polynomials (WTerms) keyed by click pattern, so repeated calls that share patterns skip recompilation. One engine may be shared across threads.

Every entry point (tr, dot, fidelity, to_fock, duankimble, emissiveload) takes an engine keyword and otherwise falls back to get_default_engine.
