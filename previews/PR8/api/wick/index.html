Wick Contraction

The computational core. Gaussian moments are evaluated by Wick contraction: a symbolic moment polynomial is compiled once into WTerms, a type-stable representation grouped by monomial degree, and then contracted against the inverse kernel by W.

Most users never call these directly — project and the metrics built on it drive them, and HybridProjectionEngine caches the compiled polynomials. They are documented because they are the extension point for new moment calculations.

Genqo.WTerms — Type
struct WTerms{B<:Tuple}

A precompiled moment polynomial as a heterogeneous tuple of WBuckets, one per degree present in the polynomial. The tuple type carries each bucket's N at compile time so iteration unrolls and each _W_bucket call specializes on its bucket's degree.
